## 三、装完之后：Shadowrocket 怎么配置

小火箭本身只是个壳，需要导入节点订阅才能用。

```
1. 打开 Shadowrocket
2. 右上角 "+" → 类型选 Subscribe（订阅）
3. 粘贴你的订阅链接 → 保存
4. 回到首页，选中刚导入的节点
5. 打开顶部总开关 → 首次会请求 VPN 权限，允许
```

**常见问题**：

- **连上了但没网** → 检查节点是否过期，或换一个节点
- **订阅更新失败** → 订阅链接需要走代理才能访问，先连一个可用节点再更新
- **提示"未受信任的企业级开发者"** → 说明装的不是 App Store 版本，是小火箭的测试版/自签版，需要去"设置 → 通用 → VPN与设备管理"信任

## 四、共享号能用多久

说实话：**不保证**。

共享号被几十上百人同时使用，苹果的风控会很快察觉并锁定账号。常见情况：

```
刚拿到 → 能登录 → 装完 App → 就够用了
```

**关键是：装完之后 App 就在你手机上了**，就算账号被锁，已安装的 Shadowrocket 照常能开。

唯一的影响是**更新**——App Store 更新时需要重新登录一个有效的外区账号。

## 五、FAQ

**Q：共享号登录提示"此 Apple ID 尚未在 App Store 使用过"？**
正常，点继续，付款方式选「无」。

**Q：搜不到 Shadowrocket？**
说明 App Store 还在国区。检查：App Store → 头像 → 账户 → 国家/地区，应该是 United States。如果显示中国，说明你退出登录后没有真正切换成功。

**Q：下载时提示需要 $2.99？**
说明这个共享号没买过 Shadowrocket。换一个号，或者用已购账号。共享号里专门标注"已购小火箭"的才是买过的。

**Q：装好后能一直用吗？**
能。App 属于你的设备，不属于账号。

**Q：为什么有些共享号一登录就提示锁定？**
被前面的人用滥了。这就是共享号的常态，多试几个。

**Q：买独享号是不是就一劳永逸？**
也不完全。独享号可以改密码、绑邮箱，但如果你在多台设备上频繁切换、或者用被苹果标记的 IP 登录，一样可能触发风控。区别是独享号你能自己申诉、自己控制。
